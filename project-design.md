# PocketSmart-AI – Project Design

## 1. System Overview

PocketSmart-AI is designed as an AI-powered smart budget planner and recommendation assistant. The system accepts expense-related information from the user and provides budget recommendations and smart saving tips.

## 2. Main Components

The project consists of the following main components:

- User Input
- Expense Tracking
- Budget Planning
- AI Recommendation
- Smart Saving Tips
- User Interface

## 3. System Workflow

1. User opens the PocketSmart-AI application.
2. User provides expense-related information.
3. The application processes the entered information.
4. The information is provided to the AI system.
5. Google Gemini generates suitable recommendations.
6. The application displays budget recommendations and saving tips to the user.

## 4. Technology Design

- Programming Language: Python
- User Interface: Streamlit
- AI Service: Google Gemini
- Application Type: AI-powered web application

## 5. User Interface Design

The interface should be simple and user-friendly. Users should be able to enter their expense information easily and view the generated budget recommendations and saving tips clearly.

## 6. Expected Design Outcome

The design provides a simple workflow connecting user expense information with AI-based recommendations, making PocketSmart-AI easy to use for personal budget planning.
